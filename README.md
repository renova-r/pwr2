# pwr2

Power and sample size calculations for one-way and two-way ANOVA models, from either an effect size or delta and sigma, with power-curve plots.

Compatibility updates by Renova.

Version 1.0.9001: metadata only: the DESCRIPTION title is in title case, the stale `Date` field is removed, and the author record is normalized with an `Authors@R` field (same authors, Pengcheng Lu as maintainer). R code, documentation and results are unchanged.

## Install

```r
install.packages("pwr2", repos = c(
  Renova = "https://renova-r.r-universe.dev",
  CRAN = "https://cloud.r-project.org"
))
```

See the [R-universe package page](https://renova-r.r-universe.dev/pwr2) for builds and installation. This release is tagged on GitHub as `renova-1.0.9001`:

```r
remotes::install_github("renova-r/pwr2@renova-1.0.9001")
```
